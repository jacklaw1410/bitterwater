# Design System

Welcome to the Design System documentation! Here you will find our foundational design tokens, built natively with standard CSS variables.

## Architecture

Our design system relies on a **3-tier token architecture**:

1. **Primitives**: Absolute values like `#f9fafb`.
2. **Semantics**: Contextual aliases like `--surface-default` and `--text-primary`.
3. **Component Tokens**: Overrides and scopes for specific UI components.

_Use the sidebar to explore Colors, Typography, Spacing, Shadows, and Radius tokens._
