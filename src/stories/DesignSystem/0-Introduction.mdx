# Bitter Water Design System

**Playful · Technical · Precise**

---

## Overview

Bitter Water is a personal portfolio showcasing interactive experiments and creative coding. This design system provides foundational tokens, components, and patterns for building cohesive, accessible, and delightful experiences.

---

## Token Architecture

2-tier CSS token system. Tokens cascade from absolute primitives to contextual semantics.

**Primitives** — Absolute values like `#f9fafb`, `1rem`, `'Itim'`

**Semantics** — Contextual aliases like `--surface-default`, `--text-primary`

---

## Brand Identity

Harmonize handwritten charm with technical accuracy. Organic, approachable, yet precise.

- **Display Font**: `Itim` — playful, handwritten charm for headlines
- **Mono Font**: `Roboto Mono` — technical precision for code

---

## Color System

Built on a 50-900 scale for precise control.

- `brand-*` — Primary actions, branding (blue)
- `gray-*` — Text, surfaces, borders
- `success-*` — Positive states
- `warning-*` — Caution states
- `error-*` — Error states

---

## Typography

Type scale from `xs` to `4xl` with weights 400-700.

- **Itim**: Headlines, brand moments
- **Roboto Mono**: Code, technical content

---

## Spacing

4px-64px scale with consistent 4px base unit.

---

## Components

**bits-ui** — Accessible primitives (Button, Input, Select)

**Custom** — Project-specific UI (Typography, FeatureCard)
